# Operations

Operating Kilo Center means keeping its services available and checking that device traffic continues to pass through them. Use this section after installation to inspect service health, logs, base-station connections, and message flow when something stops working.

[Operations and Troubleshooting](operations-and-troubleshooting.md) provides the checks and common failure paths. If the services are healthy but no device messages arrive, revisit [Onboarding](../onboarding/README.md) to verify the base station, endpoint registration, and first uplink. Have access to the installation and its logs before following operational checks.
