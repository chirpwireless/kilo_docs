# Getting Started

Kilo Center is the MIOTY service center that manages communication between wireless devices, base stations, and connected applications. This section takes you from choosing an installation route to a running service with its essential configuration checked.

Start with [Architecture and Components](architecture-and-components.md) to understand the data path, then check the [Prerequisites](prerequisites.md) for your route:

- [Docker Compose](installation-docker-compose.md) runs the stack in containers.
- [Linux Host](installation-linux-host.md) covers a host installation.
- [Local VM and Automation](installation-local-vm-and-automation.md) covers a virtual-machine setup.
- [Kubernetes (Helm)](installation-kubernetes-helm.md) covers a cluster installation.

Review [Configuration Basics](configuration-basics.md) before connecting equipment. Once the services are running, continue with [Onboarding](../onboarding/README.md) to connect a base station and verify device traffic.
