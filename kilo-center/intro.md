# Intro

### Overview

KiloCenter is an open-source, production-ready MIOTY Service Center.

It is built for organizations that need to run MIOTY networks with confidence, whether for private deployments, public infrastructure, or hybrid operating models. KiloCenter gives operators and product teams a single platform to manage network operations, connect applications, and scale from pilot to production.

### MIOTY-Native Design

KiloCenter is not a generic IoT stack adapted to MIOTY. It is MIOTY-native by design, with architecture and workflows aligned to MIOTY Service Center requirements and real-world operating needs.

### Core Platform Capabilities

At a high level, KiloCenter provides:

* A control plane for MIOTY network operations
* A web interface for managing infrastructure and device fleets
* Secure multi-tenant boundaries for customer and organizational isolation
* Integration interfaces for application and platform teams
* Operational workflows designed for production environments

### APIs and Integrations

KiloCenter also provides a gRPC-first API surface for high-performance integrations and platform extensions, alongside MQTT-based event and command integration for message-driven architectures.

### Editions

The platform roadmap includes three editions:

* **Community Edition** for open-source adoption, development, testing, and controlled deployments
* **Enterprise Edition (Planned, In Progress)** for organizations that require full production capabilities, advanced operations, and commercial support
* **KiloCenter Cloud (Planned, In Progress)** as a fully-managed, SLA-backed cloud subscription so teams can focus on delivering value while KiloCenter handles production network-server operations

### Cloud Evaluation

A free discovery tier for KiloCenter Cloud is planned to let teams evaluate the managed platform before production rollout.

### Summary

In short, KiloCenter is the foundation for building and operating modern MIOTY services: open where it should be, operational where it must be, and built to integrate cleanly with the systems around it.
