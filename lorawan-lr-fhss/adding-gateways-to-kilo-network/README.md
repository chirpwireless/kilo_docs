# Adding LoRaWAN gateway to Kilo

You can add any **LoRaWAN** or **LR-FHSS** gateway to the **Kilo IoT Platform**.

Adding a gateway is straightforward and can be completed in just a few simple steps. The platform is compatible with any LoRaWAN or LR-FHSS gateway from various manufacturers, as long as it supports the **LoRa Basics™ Station** protocol.

LoRaWAN is known for its long-range communication and excellent wall penetration, making it ideal for broad coverage in both indoor and outdoor environments.

However, to ensure optimal performance, it’s important to assess signal quality before installing any devices. This can be done using a [LoRaWAN network tester](https://shop.kiloiot.de/produkt-kategorie/typ/field-tester/). A signal strength above **-90 dBm** typically indicates that installing an indoor LoRaWAN gateway could significantly improve connectivity.
