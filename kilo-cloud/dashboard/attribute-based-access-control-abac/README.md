# Attribute Based Access Control (ABAC)

Kilo now supports **Attribute-Based Access Control (ABAC)** — a flexible, modern permission model that allows granular control over what users can view or edit on the platform.

This feature is especially valuable for **platform dealers** and **corporate clients** who manage multiple employees, partners, or sub-organizations and need precise access separation.

ABAC ensures that each user only sees the data and features relevant to their responsibilities — without limiting scalability or flexibility.
