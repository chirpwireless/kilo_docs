# Official Links

Use these official Kilo sites to explore the products, open your workspace, read documentation, integrate software, or find project hardware.

- [Kilo website](https://kiloiot.io/) — product information and starting points.
- [Kilo Cloud application](https://app.kiloiot.io/) — sign in to the hosted IoT Server.
- [Kilo documentation](https://docs.kiloiot.io/) — setup guides and product reference.
- [Kilo API reference](https://api.kiloiot.io/) — supported API operations, request fields, and required scopes.
- [Kilo Electronics hardware store](https://kiloelectronics.com/) — sensors, gateways, and other project hardware.

Kilo Cloud manages devices and data; Kilo Electronics is the separate hardware store. Choose the destination that matches what you want to do.
