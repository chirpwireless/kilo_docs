# Adding and Managing Users

### Add a New User

1. Log in to your organization account.
2. Go to **Dashboard → Users**.
3. Click **Add User**.
4. Enter the user’s **name** and **email**.
5. Select which **pages** they can access.
6. Choose an access level for each page:
   * **Edit** – can create and modify content.
   * **View** – can view but not change anything.
   * **No access** – cannot see the page.
7. Click **Add User**.
8. The invited user receives an email and joins by clicking the provided link.

Once the user joins, they appear in the organization’s user list with their assigned permissions.
