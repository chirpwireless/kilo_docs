# Adding and Managing Users

Both **Owners** and authorized **Editors** can add users to an organization.\
Each user receives a customized set of permissions defined at the page level (**Edit**, **View**, or **No Access**).

A **user** may be a newly created Kilo account or user may already have their **own Kilo account** with own connected devices or their own organizations.\
For example, you might have created and used your own Kilo account to manage personal devices or projects.\
Later, another organization owner can invite you to **their organization** — where you’ll have **limited access rights** depending on what permissions are assigned to you (for example, _View-only_ access to dashboards or _Edit_ access for selected pages).

This flexible design allows professionals, dealers, and integrators to collaborate securely across organizations without sharing full administrative access.

***

#### Add a New User

1. **Log in** to your organization account.
2. Go to **Dashboard → Users**.
3. Click **Add User**.
4. Enter the **User’s Name** and **Email Address**.
5. Select which **pages or modules** the user should have access to.
6. Choose an **Access Level** for each page:
   * **Edit** – User can create and modify content.
   * **View** – User can view but not change anything.
   * **No access** – User cannot see the page.
7. Click **Add User** to send an invitation email.
8. The invited user receives an email with a join link.
9. Once the user accepts, they appear in the **User List** with their assigned permissions.

***

#### Managing Existing Users

After a user has joined:

* The **Owner** or an authorized **Editor** can edit the user’s name, email, or page permissions.
* Permissions can be updated at any time without re-inviting the user.
* Users can be **removed** if they no longer need access.

> **Note:** Invited users cannot access any part of the organization until they accept the invitation.\
> Each user’s permissions are specific to that organization — even if they belong to multiple organizations on the Kilo platform.
