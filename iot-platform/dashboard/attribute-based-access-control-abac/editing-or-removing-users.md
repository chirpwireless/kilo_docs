# Editing or Removing Users

### Edit a User’s Permissions

1. Navigate to **Users**.
2. Find the user in the list.
3. Click **Edit**.
4. Adjust their access per page (Edit / View / No access).
5. Save changes.

### Remove a User

1. Open **Users**.
2. Click the **Delete** icon next to the user’s name.
3. Confirm removal.

The user immediately loses access to your organization’s data.
