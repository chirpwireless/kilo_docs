# Security assessment status

Kilo is implementing and checking its information security management system for the hosted platform and applicable software products. This is the set of policies, responsibilities and working controls used to protect the service.

Kilo does not currently publish an ISO/IEC 27001 certification, SOC 2 report, BSI C5 attestation or CSA STAR listing. Internal documentation and checks are not independent certification.

When an assessment is complete and approved for publication, the published information will identify the company and service assessed, scope, assessor, date, limitations and supporting evidence. A hosting provider's assessment covers that provider's stated services and period; it does not automatically extend to Kilo.

For practical setup and ongoing use, read the [Customer security guide](customer-security-guide.md). For a possible vulnerability, follow [Report a security vulnerability](incident-response-and-vulnerability-reporting.md).
