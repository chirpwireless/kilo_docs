# Maps and Tracking

This section covers the spatial features of the Kilo IoT Server — placing devices on interactive maps for location-based visibility, and viewing GPS tracking history for tracker-type devices.

Maps add a physical dimension to your deployment. Instead of scanning a device list, you can see where each sensor or gateway sits within a building, across a campus, or along a delivery route.

## In this section

- [Device Maps](device-maps.md) — View device locations on an interactive map and add location data for new devices.
- [GPS Tracking](gps-tracking.md) — View location history, routes, coordinates, and signal data for tracker devices.
