# Device Sharing

Device sharing lets you grant another user access to a specific device by email. Shared devices appear under **Settings > Device sharing** in the sidebar, where you can review and revoke access at any time.

## Shared Devices Inventory

The Device sharing page displays a table of every device you have shared:

| Column | Width | Content |
|---|---|---|
| **Device** | 25 % | Device name |
| **Type** | 25 % | Device type |
| **Email** | 30 % | Recipient's email address |
| **Action** | --- | Trash icon to unshare |

If no devices have been shared, the page shows the message: *"You don't have any shared devices -- it will be visible here."*

### Revoking Access

To unshare a device, click the trash icon in its row. A confirmation dialog appears:

> Are you sure you want to unshare this device with user {email}?

Click **Unshare** to confirm. The device is removed from the table immediately and the recipient loses access.

## Sharing a Device

Sharing is initiated from the individual device's settings panel rather than from this page. Open a device, navigate to its settings, enter the recipient's email address in the **Share device** section, and click **Share**. The recipient appears in a list below the field, with an **X** button to remove access directly from the device view.

For full instructions on locating and editing device settings, see [Device Management](../devices/device-management.md).
