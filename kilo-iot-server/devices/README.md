# Devices

Every physical device registered on the Kilo IoT Server becomes a Digital Twin — a complete digital representation that captures the device's identity, sensor configuration, telemetry history, photos, and connection binding in one persistent model.

The Devices section covers the full device lifecycle: registering new devices through connectors, managing device configuration and physical hardware bindings, and defining the metric templates that normalize raw sensor data into a consistent format across your deployment.
