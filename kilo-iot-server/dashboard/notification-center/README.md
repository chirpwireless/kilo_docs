# Notification Center

The **Notification Center** is where you can **set up, manage, and review alerts** generated by your automation rules. It provides a centralized view of everything that happens across your monitored devices and systems.

***

### Opening Notifications

1. In the left navigation menu, click **Notifications**.
2. The **Notification Center** opens on the right.

This section is your main hub for:

* Viewing incoming alerts
* Managing notification rules
* Configuring notification preferences

***

### Notification Center Layout

<figure><img src="../../../.gitbook/assets/image (2) (1).png" alt=""><figcaption></figcaption></figure>

At the top-left of the Notification Center, you will see three tabs:

* **Inbox**
* **Rules**
* **Settings**

Below the tabs is a **Search field** that allows you to quickly search and filter notifications, which is especially useful when you have a large number of alerts.
