# Inbox

The **Inbox** is one of the places where you can view notifications generated by your automation rules and monitoring system. It provides a centralized list of alerts so you can review incidents, verify system activity, and track resolved events over time.

Each notification contains:

* **Subject** – what the alert is about
* **Status** – current state of the alert (e.g., active, resolved)
* **Type** – severity level (e.g., critical, warning, info)
* **Message** – full alert text
* **Date & Time** – timestamp of when the notification was created

#### Example Notification

| Subject    | Status   | Type     | Message                              | Date & Time    |
| ---------- | -------- | -------- | ------------------------------------ | -------------- |
| Water leak | Resolved | Critical | Water leak detected in the basement! | 07.08.25 15:03 |

***

### Searching Notifications

If you have many notifications in your Inbox:

1. Click into the **Search field**
2. Enter a keyword (e.g., “leak”, “temperature”, “boiler”, “door”)
3. The list updates to show only matching notifications

Search helps you quickly locate:

* A specific incident
* Notifications for a specific device or system
* Alerts from a certain period of time
