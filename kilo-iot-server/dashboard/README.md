# Kilo IoT Server

Kilo is an **IoT server** for **device management, data collection, processing, visualization, advanced rules engine, and IoT alerting**.\
The server is available as a **fully managed Cloud deployment** or as a **self-hosted On-Premise installation**.

#### Kilo Cloud IoT Server

Kilo Cloud is a fully managed, scalable, and fault-tolerant IoT server built to support IoT deployments from prototype to production.\
It is designed for organizations and individuals who want to automate, scale, and optimize their connected systems without the overhead of maintaining infrastructure.

Kilo IoT is the ideal choice if you:\
Want to reduce maintenance and IT costs\
Don’t have internal technical resources to manage your own servers\
Need enterprise-grade reliability and uptime

If you don’t want to coordinate with multiple vendors for visualization, LPWAN servers, connectivity, or the device supply chain, Kilo provides everything in one place for your convenience—while still giving you the freedom to choose other suppliers for devices, connectivity, and more, ensuring long-term flexibility and scalability without vendor lock-ins.

#### Kilo On-Premise IoT Server

Kilo On-Premise is the same IoT server deployed within your own infrastructure.\
It is intended for security-focused organizations that want to retain full control over their data, access policies, and network boundaries.
