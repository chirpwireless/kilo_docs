# Navigation Menu

The left sidebar provides access to all sections of the Kilo IoT platform.

### Menu Structure

The navigation menu is organized into the following sections:

### **Dashboard**

* **Overview** — Your main board with summary widgets
* **Dashboards** — Custom dashboards you've created (expandable to show all your dashboards organized by folder)

### **Device Management**

* **Devices** — View and manage all your devices
* **Gateways** — View and manage all your gateways

### **Automation**

* **Rules engine** — Create automation rules based on device data
* **Notifications** — View and manage your notification settings and inbox

### **Settings**

* **Profile settings** — Manage your account profile
* **Locations** — Configure locations for organizing devices
* **New device request** — Request support for new device types
* **Changelog** — View recent platform updates (opens external link)

### **External Links**

* **Docs** — Access the Kilo IoT documentation (opens docs.kiloiot.io)

### Collapsing the Menu

You can collapse the sidebar to free up screen space:

1. Hover over the left edge of the sidebar
2. Click the collapse arrow
3. The menu shrinks to show only icons
4. Hover over or click an icon to access menu items
5. Click the expand arrow to restore the full menu

### Theme Toggle (Dark/Light Mode)

Kilo IoT supports both light and dark themes to suit your working environment and personal preference.

**Light Mode**

* Best for well-lit environments
* High contrast for detailed data viewing
* Default theme for new accounts

**Dark Mode**

* Reduces eye strain in low-light conditions
* Ideal for monitoring dashboards in control rooms or NOCs
* Lower screen brightness can save battery on laptops and mobile devices

**How to Switch Themes**

1. Look for the theme toggle icon at the bottom of the sidebar (sun/moon icon)
2. Click the toggle to switch between light and dark themes
3. The interface updates immediately
4. Your preference is saved automatically and persists across sessions

Tip: If you frequently work in different lighting conditions, the theme toggle provides quick access without navigating to settings.
